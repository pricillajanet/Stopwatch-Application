Stopwatch Application

A simple stopwatch application built using Java Swing. It allows users to measure elapsed time, pause and resume the stopwatch, record lap times, and reset the timer.

Features
- Start the stopwatch
- Pause and resume timing
- Reset elapsed time
- Record lap times
- Display lap history
- Popup validation when recording laps while stopped
- Scrollable lap history

Technologies Used
- Java
- Java Swing
- Swing Timer

 Concepts Practiced
- Event handling
- Lambda expressions
- ArrayList
- Swing Timer
- GUI components
- Conditional statements
- Layout management

How to Run
1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Run `Main.java`.

Project Preview
The application displays elapsed time, recorded lap history, and Start, Pause, Reset, and Lap buttons.
